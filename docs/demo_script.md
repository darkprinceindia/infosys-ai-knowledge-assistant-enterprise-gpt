# Demo walkthrough and narration

Target length: about 4–6 minutes. Record the browser at a readable scale and keep the API key and environment settings off screen.

| Scene | On-screen action | Suggested narration |
| --- | --- | --- |
| 1. Problem | Show sign-in and Ask assistant. | “Teams lose time finding the right version of an SOP, policy, or runbook. This assistant retrieves approved knowledge and gives employees an answer they can verify.” |
| 2. Cited answer | Sign in as administrator. Ask “What is the annual leave request process?” | “The assistant classifies the question as HR, invokes a read-only MCP search tool, and builds an answer from the permitted policy passage. The citation identifies the document and section.” |
| 3. Source inspection | Open citation `[1]`. | “The employee can inspect the original source, owner, classification, and effective date before acting.” |
| 4. Ingestion | Open Knowledge library and upload a short approved sample document. | “Knowledge owners provide department, classification, owner, and dates. The system validates and indexes sections for retrieval.” |
| 5. Access control | Sign out; sign in as Delivery employee. Ask the HR question. | “The same HR source is outside this role's scope. The assistant declines instead of leaking a snippet or inferred answer.” |
| 6. Operations | Sign in as administrator; open Quality analytics. | “Operations can see usage, no-answer rate, cited-answer coverage, connector events, and repeated questions that indicate knowledge gaps.” |
| 7. Closing | Show Connectors page. | “The implementation demonstrates a complete governed flow, with an MCP tool boundary and room to add approved enterprise systems.” |

## Narration options

The written script is ready to read in your own voice. **No voice sample is required** for that. If you later want an AI-generated narration that resembles your own voice, provide a clean recording and explicitly request that separate production step; use only a voice you are authorized to reproduce. A standard synthetic narrator also needs no sample. The app itself does not contain a voice-cloning feature.
