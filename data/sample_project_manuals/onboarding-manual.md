# Project onboarding manual
Owner: Project Management Office
Effective date: 2026-01-01
Classification: Internal

## New project checklist
Create a project workspace, register the project owner, confirm contractual scope, assign delivery and engineering leads, and link approved SOPs. Record access requests before team members receive project material.

## First-week review
The project manager reviews milestones, risks, dependencies, and escalation contacts with the team. Open questions are logged with an owner and due date. Reuse the approved delivery escalation SOP for incident handling.
